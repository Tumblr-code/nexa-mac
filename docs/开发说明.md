# nexa 原生应用源码

Swift + SwiftUI + AppKit，无第三方代码依赖。产品名称为 nexa，不使用 pulse。硬件信息读取当前机器，界面按已确认的 Mac Studio 品牌预览实现。

## 构建

需要 Apple Silicon Mac、Xcode Command Line Tools 和 macOS 14 以上 SDK。以下命令都在仓库根目录执行。构建默认将软件、ZIP 和图标输出到源码目录的上一级（仓库根目录，已在 `.gitignore` 中忽略）；编译缓存与中间图标集放在系统临时目录。

```bash
bash NexaSource/build.sh
```

可通过第一个参数指定其他输出目录。运行中的应用应先退出再更新。构建脚本不会覆盖标识不同的同名应用，不会修改 Gatekeeper 或删除隔离属性。

## 文件

- `App.swift`：应用生命周期、状态栏、弹出面板、采集调度订阅和验证入口。
- `Metrics.swift`：Mach CPU / VM 数据、sysctl 内存压力、网络接口计数、磁盘容量；后台队列采集，主线程发布。
- `Views.swift`：原生概览、趋势线、用量条、占用最高的应用、设置和自动适配的文字颜色。
- `AppActivity.swift`：按应用归并进程的 CPU 与内存采样、面板与窗口共用的采样调度、列表的搜索和排序。
- `ActivityView.swift`、`ActivityWindow.swift`：应用活动窗口。
- `Preferences.swift`：偏好持久化与 `SMAppService` 登录项管理。
- `Brand.swift`：同一套矢量羽毛绘制，菜单栏使用模板图像；以及取自 nexastore.cn 的配色、字体和组件（组合按钮、圆形箭头、橙色标签、细线）。
- `IconMaker.swift`：生成完整图标集和 1024 像素主图标。
- `Assets`：网站同款的 Manrope 可变字体（WOFF2，CoreText 直接加载）和原始 OFL 许可。
- `Tests/MetricsTests.swift`：算法边界、趋势线取点与缩放、实际采样检查。
- `Tests/ActivityTests.swift`：进程归属、CPU 时间换算、列表查询和实时采样检查。

## 验证命令

```bash
xcrun swiftc -swift-version 5 \
  NexaSource/Metrics.swift \
  NexaSource/Tests/MetricsTests.swift \
  -o /tmp/nexa-metrics-tests
/tmp/nexa-metrics-tests
```

```bash
xcrun swiftc -swift-version 5 \
  NexaSource/AppActivity.swift \
  NexaSource/Tests/ActivityTests.swift \
  -o /tmp/nexa-activity-tests
/tmp/nexa-activity-tests
```

```bash
"$HOME/Applications/Nexa.app/Contents/MacOS/Nexa" --diagnostics
```

退出正式实例后，可验证菜单栏交互或生成界面截图。界面测试使用独立的偏好域，不修改正常使用的偏好，不启用登录项。截图目录须事先存在。

```bash
"$HOME/Applications/Nexa.app/Contents/MacOS/Nexa" --smoke-test
"$HOME/Applications/Nexa.app/Contents/MacOS/Nexa" --render-previews /tmp
```

`--smoke-test` 会临时打开菜单栏面板，验证打开、尺寸、CPU / 内存指标、设置切换、关闭及重新打开，再打开应用活动窗口验证实时应用列表和关闭，然后退出。`--render-previews` 输出完整浅色、完整深色、精简、设置，以及应用活动窗口的浅色和深色截图。截图默认在启动 3 秒后开始；设置环境变量 `NEXA_PREVIEW_WARMUP`（秒，最多 120）可以等趋势线采满再截。

## 设计与边界

默认单羽毛菜单栏图标。面板基准宽 320 pt，所有尺寸和字号都经 `u()` 乘以界面大小系数（1.0 / 1.2 / 1.4，默认 1.2），所以默认实际宽 384 pt。界面跟随 nexastore.cn：纸白 `#FAFAFA` / 墨黑 `#171715` 的暖中性色，强调色 `#F15436`（深色主题 `#FF795D`），CPU 用商品卡样式的炭黑卡片承载，卡片做成磨砂玻璃：背后色块的橙色以渐变扩散透出，叠一层细颗粒和受光的上边缘（不用模糊滤镜，离屏截图也能如实渲染），数字用中等字重的 Manrope。不使用系统毛玻璃，弹出面板的箭头也垫了纸色。品牌橙红只做强调；警告用单独的橙和红，不与强调色混用。所有颜色都是随外观变化的动态色，防止主题切换后文字与背景失配。面板即时展开关闭，避免弹出动画延迟关闭状态。

采样错误不填充模拟值。CPU 采用无符号差值处理计数器回绕，网络计数重置与接口切换重新建立基线。定时器在后台串行队列执行，睡眠暂停，周期变更时取消旧计时器；代次检查防止旧采样覆盖新状态。复用并释放 Mach 主机端口。

CPU 趋势线画最近 60 秒，按采样时间而不是序号定位，所以休眠或改刷新间隔留下的空档不会被拉伸；纵轴上限按峰值向上取 25% 的整数倍，最低 25%。

应用活动只做实时查看，不统计时长，不落盘。只读取当前用户的进程，把辅助进程和子进程归并到所属应用，嵌在其他应用包内的辅助应用也并入宿主，不单独成行；CPU 为占整机的比例。`proc_pid_rusage` 的 CPU 时间是 Mach tick，在 Apple 芯片上不是纳秒，须按 `mach_timebase_info` 换算。面板和窗口共用一个采样器，只在其中之一显示时运行；从面板切到窗口时不重置 CPU 基线。

当前没有温度读数、风扇控制、私有 SMC 接口、联网遥测或自动更新。登录项的实际登录启动需要单独实机验证。发布到其他设备前需要 Developer ID 签名和公证。
