# nexa for Mac

原生 macOS 菜单栏工具，版本 1.2.0。

## 打开与使用

- 已安装位置：`~/Applications/Nexa.app`。
- 点击菜单栏的羽毛图标即可展开；再次点击收起，点击面板外部或按 Escape 也可关闭。
- 默认不显示 Dock 图标。关闭面板后，状态采集仍在后台继续。
- 右键点击羽毛，可打开设置、应用活动或退出 nexa。
- 面板底部也提供设置、应用活动和退出按钮；点击面板里的“占用最高”一行同样打开应用活动。
- 设置支持：仅图标、CPU 或内存指标；2 / 5 / 10 秒刷新；跟随系统、浅色、深色；界面大小（标准 / 大 / 特大，默认“大”）；精简面板。
- 登录时启动默认关闭。可在设置中主动开启；macOS 要求确认时，按界面提示进入系统设置。

## 面板

界面与 nexastore.cn 同一套视觉：纸白与墨黑的底色、橙红强调色、Manrope 数字，以及商品卡的样式。

- CPU 放在一张磨砂质感的炭黑卡片上（卡片后的橙色色块会柔和地透出来），带最近 60 秒的趋势线。纵轴会随峰值自动放大，最低按 25% 画，所以空闲时也能看出起伏；悬停可看峰值和当前纵轴上限。趋势线左侧的空白表示那段时间没有采样（刚启动、休眠或改过刷新间隔）。
- 内存和磁盘各带一条已用比例。内存压力偏高、磁盘已用超过 85% 时变橙色，压力较高、超过 95% 时变红色。
- “占用最高”显示此刻占用 CPU 最多的应用，只在面板打开时读取。

## 应用活动

- “应用活动”是 nexa 自带的实时窗口，不跳转到系统的活动监视器。
- 列出当前用户正在运行的应用，显示 CPU、内存和进程数；辅助进程、子进程和嵌在应用包内的辅助应用都已归并到所属应用，前台应用有标记。
- 可按应用名称或 PID 搜索，用上方的标签按 CPU、内存、名称排序。
- CPU 数字旁的横条用来在应用之间比较长短，以当前最高的应用为满格；数字本身是绝对值。
- 右键点击某一行，可切换到该应用或在访达中显示它。
- 只做实时查看：不统计使用时长，不保存任何记录。窗口关闭或最小化、面板也收起后，停止读取各应用的资源占用。

## 真实数据

- CPU：系统 CPU 时间计数的增量，分为用户和系统使用率。启动和唤醒后需要一个采样周期形成速率。
- 各应用的 CPU 是占整机全部核心的比例，因此数值会比活动监视器里按单核计的百分比小。各应用内存为其可读取进程的物理占用之和，个别进程读不到时标注“部分数据”。
- 内存：本机实际物理内存；已用量包含应用、联动和压缩内存，排除文件缓存与可清除内存。内存压力直接读取系统状态。悬停可查看交换空间。
- 网络：当前主物理接口的字节计数增量，优先采用 64 位计数。不重复统计 VPN 隧道。此指标不是互联网测速结果。
- 磁盘：用户目录所在 APFS 文件系统的总容量与可用空间，每 30 秒刷新。
- 内存显示沿用 macOS 常见的二进制 GB 口径；磁盘和网络速率使用十进制单位。
- 无法读取的指标显示“—”或“暂不可用”，不使用演示数据。
- 休眠时暂停采集，唤醒后重新建立采样基线。

## 图标与品牌

主图标采用黑色圆角底、白色羽毛，保留 nexa 品牌标识。内含完整 16–1024 像素图标尺寸及 Retina 资源，并已生成应用使用的 `.icns`。

菜单栏使用单色模板图标，自动适配系统菜单栏背景。字标和数字使用网站同款的 Manrope 可变字体，字体许可随应用附带。浅色和深色的配色取自网站对应的主题。

## 隐私与权限

状态采集不发送网络请求，不上传数据，不需要管理员、辅助功能、屏幕录制或完全磁盘访问权限。只有点击官网链接才会打开网站。

应用活动只在内存中保留当前这一次读数，不写入磁盘，不记录窗口标题、输入内容或屏幕画面。

这是一份本机编译、ad-hoc 签名的版本，尚未使用 Apple Developer ID 签名和 Apple 公证，不是用于广泛分发的正式发布包。

## 交付文件

- 已安装的应用：`~/Applications/Nexa.app`。

移动应用后，应重新设置登录时启动。

## 兼容与卸载

当前构建为 Apple Silicon 版本，最低 macOS 14。

卸载时先关闭“登录时启动”，退出 nexa，再移除应用。偏好设置使用 `cn.nexastore.nexa` 域，不会改动系统监控设置。
